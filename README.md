# AWS Training - Amplify Gen 2 + React + Vite

A fullstack web application built with **React 18**, **Vite**, **TypeScript**, and **AWS Amplify Gen 2**. This project demonstrates how to set up code-first backend resources (Auth & Data) on AWS, provision cloud sandboxes, and build a modular frontend with public viewing and admin management capabilities.

---

## ✨ Key Features

- **Guest Public Player Catalog**: Anyone can browse the player list without needing an account.
- **Admin Management Portal**: Protected route requiring admin authentication via Amazon Cognito.
- **Full Player CRUD Operations**: Logged-in admins can Create, Read, Update, and Delete player entries.
- **Realtime Data Syncing**: Uses Amplify Data to sync database changes to the UI instantaneously.

---

## 🛠️ Tech Stack

- **Frontend**: [React 18](https://react.dev/), [Vite](https://vitejs.dev/), TypeScript, Vanilla CSS (Glassmorphism design system).
- **UI Components & Auth**: [`@aws-amplify/ui-react`](https://ui.docs.amplify.aws/) `<Authenticator>`.
- **Backend Infrastructure**: [AWS Amplify Gen 2](https://docs.amplify.aws/gen2/) (`@aws-amplify/backend`, `@aws-amplify/backend-cli`).
- **Authentication**: AWS Amplify Auth (Amazon Cognito User Pool & Identity Pool).
- **Database & API**: AWS Amplify Data (AWS AppSync GraphQL API + Amazon DynamoDB).

## 📁 Architecture & Folder Structure Guidelines

To maintain code readability and prevent bloating single files like `App.tsx`, the frontend is organized into decoupled, single-responsibility modules:

```text
aws-training/
├── amplify/                      # AWS Amplify Gen 2 Backend Definitions
│   ├── auth/                     # Cognito Authentication schema & configuration
│   │   └── resource.ts
│   ├── data/                     # AppSync GraphQL & DynamoDB Player model schema
│   │   └── resource.ts
│   ├── backend.ts                # Main backend configuration entrypoint
│   └── tsconfig.json
├── src/                          # React Frontend Application Source Code
│   ├── assets/                   # Static images, icons, and media files
│   ├── components/               # Modular UI Components
│   ├── constants/                # App configuration, routes, and initial constants
│   ├── pages/                    # Main route pages (PublicPlayersPage, AdminPage)
│   ├── services/                 # Amplify client initialization & API helper services
│   ├── types/                    # TypeScript type definitions and interfaces
│   ├── utils/                    # Helper functions (formatters, validators)
│   ├── App.css                   # Custom UI styles
│   ├── App.tsx                   # Main Router component
│   ├── index.css                 # Global styling reset & design system tokens
│   ├── main.tsx                  # React DOM entry point
│   └── vite-env.d.ts
├── amplify.yml                   # AWS Amplify Hosting build configuration
├── amplify_outputs.json          # AWS Cloud outputs (generated by ampx sandbox)
├── package.json                  # Dependencies and project scripts
├── tsconfig.json                 # TypeScript compiler configuration
└── vite.config.ts                # Vite bundler setup
```

## 📋 Prerequisites

Before running or deploying the application:

1. **Node.js**: v20.x or later.
2. **npm**: v10.x or later.
3. **AWS CLI & Credentials**: Configured locally with `aws configure` using valid AWS credentials.

## 🚀 Getting Started & Local Workflow

### 1. Clone & Install Dependencies

```bash
git clone https://github.com/quannguyen-agilityio/aws-training.git
cd aws-training
npm install
```

### 2. Typecheck & Backend Sandbox

Deploy isolated backend infrastructure to AWS Cloud in real-time:

```bash
# Verify TypeScript safety
npm run typecheck

# Provision AWS Cloud resources (Cognito, AppSync, DynamoDB)
npm run amplify:sandbox
```

> `ampx sandbox` will output an auto-generated `amplify_outputs.json` file in the root directory.

### 3. Run Frontend Development Server

In a separate terminal window:

```bash
npm run dev
```

Open `http://localhost:5173` in your browser.

## 📜 Available Scripts

| Command                   | Description                                                         |
| :------------------------ | :------------------------------------------------------------------ |
| `npm run dev`             | Starts Vite local development server with HMR.                      |
| `npm run typecheck`       | Runs TypeScript type checking without emitting files.               |
| `npm run build`           | Compiles TypeScript and builds production bundle in `dist/`.        |
| `npm run preview`         | Previews production build locally.                                  |
| `npm run lint`            | Runs ESLint rules across `.ts` and `.tsx` files.                    |
| `npm run amplify:sandbox` | Provisions personal AWS sandbox environment (`ampx sandbox`).       |
| `npm run amplify:outputs` | Generates/updates `amplify_outputs.json` (`ampx generate outputs`). |
